# AI Personal Finance Manager

A Flask web application for recording income and expenses, viewing a financial dashboard, and predicting monthly expenses using a Random Forest machine-learning model.

## Main Features

- Add and delete income or expense transactions
- View total income, total expenses, and current balance
- View category-wise expense chart
- Store transactions in SQLite
- Predict monthly expense and estimated savings
- Responsive user interface with Indian rupee currency
- Ready for local use and Gunicorn deployment

The following files are generated automatically:

```text
expense_model.pkl   Generated by train_model.py

```

## Run the Project

### 1. Open the project folder

```bash
cd AI_Personal_Finance_Manager
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate it

Windows:

```bash
venv\Scripts\activate
```

Linux or macOS:

```bash
source venv/bin/activate
```

### 4. Install packages

```bash
pip install -r requirements.txt
```

### 5. Train the model

```bash
python train_model.py
```

This reads `dataset/finance_data.csv` and creates `expense_model.pkl`.

### 6. Run the Flask application

```bash
python app.py
```

### 7. Open the application

```text
http://127.0.0.1:5000
```

## Production Command

```bash
gunicorn app:app
```

For production deployment, set a secure `SECRET_KEY` environment variable.
